# Privacy Policy for WhatsHide

**Effective Date:** August 14, 2026

Your privacy is of paramount importance to us. This Privacy Policy governs the operation of the **WhatsHide - WhatsApp Web Privacy Shield** Chrome extension (the "Extension").

## 1. Local Operation & Zero Data Collection
WhatsHide is designed with a **privacy-first architecture**. The Extension operates entirely locally within your Google Chrome browser window on `web.whatsapp.com`. We do not collect, store, transmit, log, track, or share any personal data, chat messages, contact names, phone numbers, avatars, financial data (IBANs/credit cards), or browsing history.

## 2. Permissions & Data Handling
- **`storage` permission:** Used exclusively to save your local user preferences (such as blur intensity settings and feature toggle states) directly in your browser's local `chrome.storage.local` storage.
- **`scripting` and Host Permissions (`web.whatsapp.com`):** Used solely to execute CSS blur effects and DOM manipulation algorithms to obscure screen text on WhatsApp Web per your explicit user request.

## 3. Third-Party Services & Remote Config
The Extension communicates securely with Supabase over HTTPS strictly to fetch dynamic app configuration settings. No personally identifiable information (PII) or chat content is ever sent to Supabase or any third party.

## 4. Compliance with Google Chrome Web Store Policy
WhatsHide strictly adheres to the **Chrome Web Store User Data Policy**, including the Limited Use requirements. The Extension does not sell user data to third parties, does not use user data for targeted advertising, and does not monitor user activity outside of WhatsApp Web.
